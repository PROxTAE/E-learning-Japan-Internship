โครงสร้างข้อมูลที่ส่ง (Request & Prompt Payloads)

ตัวอย่างข้อมูล JSON ที่ Frontend ส่ง และ Prompt ที่ Server สร้างส่งต่อให้ Ollama

📤 Frontend ส่งไปที่ /api/chat

JSON Request Body // POST /api/chat — AI Chatbot { "messages": [ { "role": "user", "content": "คำถามก่อนหน้า..." }, { "role": "assistant", "content": "คำตอบก่อนหน้า..." } ], "prompt": "นักเรียน Protae มีปัญหาตรงไหน?", "context": { // ดึงมาจาก data-ai-context-data attribute "studentId": "std_101", "name": "Protae", "scorePercent": 40, "detailedAnswers": [ { "index": 1, "isCorrect": false, "confusion": "high", "time": 45 } ] }, "lang": "th" }

📥 Server ตอบกลับ Frontend

JSON Response { "message": "นักเรียน Protae ดูเหมือนมีความสับสน... ในเรื่องการตั้งชื่อตัวแปร...", "model": "qwen3:8b" }
💡
Next.js Server จะประกอบ System Prompt บังคับภาษาไทย/EN/JP และแนบ Context JSON ก่อนส่งต่อให้ Ollama

📤 Frontend ส่งไปที่ /api/analyze-quiz-log

JSON Request Body // ส่ง logId เพื่อให้ Server ดึงข้อมูลเอง { "logId": "665e8aef1f63004e0e227abc", "lang": "th" } // หรือส่ง log โดยตรง (ไม่ผ่าน DB) { "log": { "session_metadata": { "student_name": "Protae", ... }, "answer_logs": [ ... ], "summary": { "total_score": 1, "full_score": 3 } }, "lang": "th" }

🧠 Server แปลงข้อมูลเป็น Text Prompt ส่ง Ollama

Prompt (text) // ผลลัพธ์จาก buildAnalysisPrompt() You are an expert learning coach... Respond ONLY in Thai. Student: Protae Quiz: Python Variables Score: 1 / 3 Confusion rate: 67% (hesitated/changed answer) Per-question breakdown: Q1: "Variable Declaration" → ❌ Wrong (hesitation). Time: 45s Q2: "Naming Rules" → ✅ Correct. Time: 12s Q3: "Scope" → ❌ Wrong. Time: 70s Please provide: 1. Overall Assessment 2. Strengths 3. Weak Areas / Topics to Review 4. Concrete Study Recommendations 5. Encouragement

📤 Frontend ส่งไปที่ Express Backend (SSE)

3 Endpoints // 1. Class-wide summary POST /api/session-history/:id/ai-summary { "lang": "th" } // 2. Per-student analysis POST /api/session-history/:id/ai-student/:studentId { "lang": "th" } // 3. Cross-session comparison POST /api/session-history/quiz/:quizId/ai-cross-session { "lang": "th" }

📥 รับกลับเป็น SSE Stream Event

Server-Sent Events // แต่ละ token ที่ Ollama ส่งกลับ data: { "token": "ผล" } data: { "token": "การ" } data: { "token": "สอบ" } data: { "token": "..." } // เมื่อประมวลผลเสร็จ data: { "done": true }
⚡
Frontend ใช้ streamAiSummary() จาก sessionHistoryApi.ts ทำการ fetch และอ่านข้อมูลจาก ReadableStream ทีละ chunk แล้ว append ข้อความใน UI แบบ Real-time

🤖 Payload ที่ส่งให้ Ollama /api/chat (Non-streaming)

POST localhost:11434/api/chat { "model": "qwen3:8b", "messages": [ { "role": "system", "content": "You are a helpful teaching assistant... Respond ONLY in Thai..." }, { "role": "system", // Context จาก UI Inspection "content": "Current element context: {...}" }, { "role": "user", "content": "นักเรียน Protae มีปัญหาตรงไหน?" } ], "stream": false, "options": { "temperature": 0.7 } }

🤖 Payload ที่ส่งให้ Ollama /api/generate (SSE Streaming)

POST localhost:11434/api/generate { "model": "qwen3:8b", "prompt": "[System Role + สถิติห้องเรียน + Prompt]", "stream": true } // Ollama ตอบกลับทีละ chunk { "response": "ภาพ", "done": false } { "response": "รวม", "done": false } { "response": "ห้อง", "done": false } { "response": "", "done": true }

การตั้งค่าโมเดล AI (LLM Configuration)

ระบบกำหนดโมเดลผ่าน Environment Variables และมี Auto-detection fallback

📁 Environment Variables

OLLAMA_MODEL qwen3:8b
OLLAMA_HOST / OLLAMA_URL http://localhost:11434
NEXT_PUBLIC_API_URL http://150.15.79.45:5000
📍
ค่า OLLAMA_MODEL ตั้งค่าใน frontend/.env.local และ backend/.env แยกกัน Fallback default คือ qwen3:8b

🔍 Model Detection Priority

1

ใช้ค่า OLLAMA_MODEL จาก .env

ถ้ามีค่า Environment Variable ระบบจะใช้โมเดลนั้นทันที (ไม่ Auto-detect)

2

Auto-detect จาก Ollama API

เรียก GET localhost:11434/api/tags ดึงรายการโมเดลที่ติดตั้ง เลือกโมเดลแรกที่พบ

3

Hardcoded Fallback

ถ้า Auto-detect ล้มเหลว (Ollama ไม่รัน) ใช้ค่า fallback คือ gemma2:9b (Frontend) หรือ qwen3:8b (Backend)

✓

ส่ง Request ไปยัง Ollama

ใช้โมเดลที่คัดเลือกแล้วส่งไปประมวลผล พร้อมคืนชื่อโมเดลกลับไปแสดงบน UI
