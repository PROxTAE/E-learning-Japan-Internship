📖 System Documentation

E-Learning Quiz Platform

Interactive Real-time Quiz Platform สำหรับห้องเรียนสด — ช่วยอาจารย์จัดสอบ ประเมินผล และตรวจจับความสับสนของนักเรียนแบบวินาทีต่อวินาที พร้อม AI Assistant วิเคราะห์ห้องเรียนทันที

Next.js 15 React + Zustand TailwindCSS i18n TH/EN/JP Node.js + Express Socket.io MongoDB Redis Ollama (Llama3/Gemma2)

F3
Confusion Detection Engine
ประเมินความสับสนจากพฤติกรรมการคลิกและเวลาตอบ
›
🔴

High Confusion

เปลี่ยนตัวเลือก ≥ 2 ครั้ง
หรือใช้เวลา > 60 วินาที

🟡

Low Confusion

เปลี่ยนตัวเลือก ≥ 1 ครั้ง
หรือใช้เวลา > 30 วินาที

⚪

None

ส่งในครั้งแรก
ใช้เวลา < 30 วินาที

function _calcConfusion(history, responseTime) {
  const changes = history.length - 1; // นับครั้งที่กดเปลี่ยนตัวเลือก
  if (changes >= 2 || responseTime > 60) return "high";
  if (changes >= 1 || responseTime > 30) return "low";
  return "none";
}

💡 Use Case

นักเรียนตอบถูก (ขึ้นเขียว) แต่อาจารย์คลิกดู Popover พบว่า High Confusion — กดเปลี่ยน 4 รอบ → รู้ทันทีว่า "เดาถูก" ไม่ได้เข้าใจจริง

🎯 UI Inspection Mode — ขั้นตอน

  1. 1คลิกปุ่ม Sparkle ✨ มุมขวาล่างเปิด AI Chat
  2. 2กดปุ่ม 🎯 Target เพื่อเข้า Inspection Mode
  3. 3เลื่อนเมาส์ → คอมโพเนนต์รองรับจะมีกรอบประสีม่วง
  4. 4คลิกเลือก (เช่น การ์ดคะแนนของนักเรียน Protae)
  5. 5ข้อมูล Context Badge (สีม่วง) จะปรากฏเหนือช่องแชท
  6. 6พิมพ์คำถาม → AI วิเคราะห์ตามบริบทที่เลือกทันที

👤 วิเคราะห์นักเรียน

ส่ง detailedAnswers — ประวัติตอบรายวินาที สถิติความมั่นใจ และครั้งที่เปลี่ยนคำตอบ

📋 วิเคราะห์ควิซ

ส่งชื่อ คำอธิบาย ระดับความยาก รหัสห้อง และสถิติคำถาม

📊 วิเคราะห์ห้องสอบ

ส่งภาพรวมจำนวนคนเข้าสอบและการตั้งค่าตัวกรองขณะนั้น
