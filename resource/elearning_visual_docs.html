E-Learning Quiz Platform

Interactive Real-time Quiz Platform สำหรับห้องเรียนสด — อาจารย์สร้างข้อสอบ จัดสอบ ติดตามการตอบแบบวินาทีต่อวินาที ตรวจจับความสับสน (Confusion Detection) บันทึกพฤติกรรมระดับ Interaction และวิเคราะห์ผลด้วย AI (Local LLM ผ่าน Ollama) ทั้งระดับห้องเรียน รายบุคคล และข้ามรอบสอบ

Next.js 16 (App Router) React 19 + Zustand 5 TailwindCSS 4 + HeroUI 3 Recharts · dnd-kit · QR i18n TH/EN/JA Node.js + Express 5 Socket.IO 4.8 JWT + bcrypt MongoDB (Mongoose 9) Redis 5 + In-memory Fallback Ollama — qwen3:8b / auto-detect

Section 1

สถาปัตยกรรม — 4 ช่องทางการสื่อสาร

🔗

REST API services/*.ts → /api/...

CRUD ควิซ, Auth (JWT), Dashboard, ประวัติเซสชัน, Interaction Log — Frontend services เรียก Express Backend ผ่าน HTTP/JSON

🔌

WebSocket Socket.IO

เฉพาะห้องสอบสด — นักเรียนส่งคำตอบ → Server ตรวจเฉลย → บันทึก Redis → broadcast ห้อง teacher:{sessionId} แบบเรียลไทม์

📨

SSE Server-Sent Events

Backend สตรีมบทวิเคราะห์จาก Ollama กลับมาทีละ token — ใช้กับ AI Summary / AI per-Student / AI Cross-Session ของ Session History

🤖

Next.js API Routes → Ollama

Frontend มี API ภายในของตัวเอง (/api/chat, /api/analyze-quiz-log) เรียก Ollama โดยตรง — ใช้กับ AI Assistant และวิเคราะห์ Log รายบุคคล

Fault Tolerance: Server เปิดได้แม้ Redis ล่ม — redisService สลับไปใช้ in-memory sessionManager อัตโนมัติ และ Redis จะ warm-up แบบ background ตอน start · Server ตรวจคำตอบกับเฉลยจริงใน MongoDB เสมอ ไม่เชื่อ flag จาก client

F6
Confusion Detection Engine
วัด "ความเข้าใจจริง" จากจำนวนครั้งที่เปลี่ยนคำตอบ + เวลาที่ใช้
›
🔴

High Confusion

เปลี่ยนตัวเลือก ≥ 2 ครั้ง
หรือใช้เวลา > 60 วินาที

🟡

Low Confusion

เปลี่ยนตัวเลือก ≥ 1 ครั้ง
หรือใช้เวลา > 30 วินาที

⚪

None

ตอบครั้งเดียว
ใช้เวลา ≤ 30 วินาที

function _calcConfusion(history, responseTime) {
  const changes = history.length - 1; // นับครั้งที่กดเปลี่ยนตัวเลือก
  if (changes >= 2 || responseTime > 60) return "high";
  if (changes >= 1 || responseTime > 30) return "low";
  return "none";
}

💡 Use Case

นักเรียน A ตอบข้อ 3 "ถูก" (ขึ้นเขียว) แต่ badge ขึ้น High Confusion — เปลี่ยนคำตอบ 4 รอบ → ครูรู้ว่าน่าจะ "เดาถูก" ไม่ได้เข้าใจจริง เรียกมาติวเพิ่มได้ ทั้งที่ระบบทั่วไปจะมองว่าผ่าน · ผลสะสมเป็น confusionCount รายข้อใน archive และ average_confusion_rate ใน Interaction Log ส่งให้ AI วิเคราะห์ต่อ
